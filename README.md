# 🚨 Internet Police (इंटरनेट पुलिस) : Apple 17 Series AI Cyber Guardian

An autonomous, cross-device AI Cyber Security Guardian & Background Agent reverse-engineered with:
- **Apple iPhone 17 / iOS 17 Design Language** (Dynamic Island, SF Pro typography, Liquid Glassmorphism, Theme Switcher) inspired by [`VoltAgent/awesome-design-md`](https://github.com/VoltAgent/awesome-design-md)
- **Local Background Internet Police Agent** (Enforces unbreakable Zero-Trust rules on Laptop & Mobile)
- **1-Click Free Model API Onboarding** (Groq Llama 3.3 70B & Qwen 27B, Google Gemini 1M Context, OpenRouter, Cerebras)
- **All-Device Permission Authorization Sheet** (Network Sinkhole, DLP Guard, WAF, Voice Jarvis Mode)
- **21:00 (9:00 PM) Daily Nightly Security Dispatch** (Automated daily intelligence briefing delivered to your chat)
- **Full Jarvis Voice Mode** (Speech Recognition & Neural Speech Synthesis in Hindi/English)

---

## 📱 Cross-Device Capability (Laptop, Mobile Phone & Tablet)
* **Progressive Web App (PWA)**: Built with `manifest.json` and `sw.js`. Open `http://<your-ip>:8080` in Safari on iPhone or Chrome on Android and tap **"Add to Home Screen"** to run as a full standalone app!
* **Responsive Layout**: Adapts automatically to phone screens, iPad tablets, and laptop/desktop displays.

## 🚀 Quick Start

1. Start Internet Police:
   ```bash
   python main.py
   ```
   Or double-click `run.bat`.

2. Open the Apple 17 Suite in your browser:
   👉 **`http://localhost:8080`**

3. Complete the Setup Wizard:
   * Select a Free API Provider (Groq, Gemini, etc.) or click to open the provider key portal in 1 click.
   * Enter your key, click **"Verify & Grant Permissions"**.
   * Click **"🛡️ ALLOW ALL PERMISSIONS"** on the Apple 17 Sheet to unlock the full animated suite!
